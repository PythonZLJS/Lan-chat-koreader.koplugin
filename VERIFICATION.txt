NEIGHBOUR CHAT 7.2 - KOREADER VERIFICATION
Date: 2026-11-11

The 7.2 host-ownership/password-flow rewrite was cross-compiled for ARMv7 and
the release archives were rebuilt and integrity-checked. The regression suite
was not run for this rewrite. Earlier results below describe 7.1 only; they do
not verify the 7.2 host setup/authentication changes.

The build runs go vet and the full Go regression suite with the compact C SQLite
driver used by the shipped plugin. The suite covers real HTTPS and pinned joins,
private message/file access, account approval/revocation, duplicate sends,
legacy database/password migration, local-content encryption, central backup
organisation/restoration, authenticated loopback control, session retention,
file transfer, nonblocking state access, and actual controller shutdown.
Efficiency checks cover bounded incremental message merging, conditional state
responses, slower hidden-window polling and revoked-session cache clearing.

LuaJIT contract tests use KOReader widget stubs (not a device emulator): window
hide/reopen and book change, both layout bounds, outside-reading gestures,
separate disconnect/stop controls, no unsolicited keyboard, explicit sending,
draft preservation, unchanged-screen redraw suppression and conditional state.

The exact ARM ELF is inspected for ARMv7/32-bit little-endian layout and absence
of a dynamic loader. C debug/symbol sections are removed. Extension loading is
disabled. Release ZIP checksum/content/permissions/integrity are checked, with
one plugin folder and no build tools, installer, private keys or chat data.
Official Go vulnerability checks run on source and the final ARM executable.
They do not establish that every vulnerability is absent, including in C code.

Only the KOReader release is produced. Physical Vera-jailbroken Kindle 12th
generation (2024), firmware 5.20.2, rendering/touch/keyboard, reading gestures,
power/suspend behaviour and performance remain unverified. No measured device
speed or battery-life claim is made.

ADDITIONAL 6.0 CHECKS
Room message/search/file isolation and direct-ID download denial, cross-room
private delivery, safe room-name reuse, room-change page reset, private admin
inbox, nonadmin control denial, kick/ban/unban cookie revocation, actual-peer
IP blocking, persisted pinned host history, reconnect and forget are covered.
Lua checks exercise the four visible navigation tabs, one-tap recent-host
controls, paginated long lists, all screen layouts at portrait/landscape sizes,
and the three-button reading popup, alongside the prior lifecycle checks.
Widget API choices were checked against upstream KOReader's ButtonTable,
TextBoxWidget and ScrollTextWidget source. Stub checks cannot validate fonts
or actual touch targets on the Kindle.

ADDITIONAL 7.0 CHECKS
Real UDP query/reply discovery, malformed/oversized/unrelated/forged responses,
scan cancellation, on/off socket lifecycle, retained TLS session while discovery
is off, stopping advertisements with the host, internal owner-admin login,
public owner-bypass denial and mandatory first-join TLS verification are tested.
Lua tests cover Host/Find cards, no-keyboard scans, tap-to-connect host results,
visible discovery state/switching, all screen bounds and existing lifecycle tests.
Layout tests use stubs, not actual KOReader font rendering or Kindle Wi-Fi.

ADDITIONAL 7.1 CHECKS
Account-switch private-cache isolation, stale queued contexts, unseen room-move
message/upload refusal, mixed-case room deletion, overlapping IP bans and
transactional legacy migration, concurrent session rotation, reserved owner
recovery under 512 occupied sessions, failed listener recovery, oversized
combined state and stale/rejected UI callbacks are covered by regression tests.
See SECURITY-REVIEW.txt for the findings and remaining limits.

FINAL RESULTS
Go vet and the full regression suite pass with Go 1.27.4 / compact C SQLite.
27 LuaJIT UI/protocol contract tests pass.
Official govulncheck v1.9.0: source and final ARM binary both report
No vulnerabilities found.
52 Go test functions cover the suite; the optional old web preview test is
skipped unless explicitly requested.
Actual binary size and SHA256 are recorded in the release BUILD-INFO.json;
ZIP checksums are in the matching .sha256 files. The ZIP contains only the
plugin folder, licenses and instructions, without data, installers or tools.

RACE-DETECTOR LIMIT
A targeted -race run was attempted. After resolving a Windows synchronization
import-library link requirement, ThreadSanitizer could not allocate shadow
memory (Windows error 87). The run did not complete and is not a passed check.
The normal concurrent session-rotation regression and all other tests passed.
